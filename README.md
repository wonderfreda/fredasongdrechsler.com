# fredasongdrechsler.com

Source for *Python Programs for Empirical Finance* (https://www.fredasongdrechsler.com), built with [Quarto](https://quarto.org).

```sh
quarto preview          # live preview
quarto render           # build into _site/
```

`_tools/convert_gsites.py` re-imports pages from the legacy Google Sites version.
